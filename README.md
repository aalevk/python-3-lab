# Каталог авиационных деталей

Лабораторная работа №3. Каталог объектов.

Проект представляет собой каталог авиационных деталей. С его помощью можно добавлять детали, получать их по ID, удалять и искать по названию или категории. Также реализовано сохранение каталога в JSON-файл и его последующая загрузка.

## Описание

Каждая авиационная деталь представлена классом `AircraftPart`. Для создания объектов используется `dataclass`.

У каждой детали есть следующие поля:

- `id` — уникальный идентификатор;
- `name` — название детали;
- `category` — категория;
- `year` — год выпуска;
- `manufacturer` — производитель;
- `material` — материал.

При создании объекта проверяются типы и значения полей. Если данные не проходят проверку, возникает исключение `IncorrectEntityError`.

## Возможности каталога

Класс `AircraftCatalog` поддерживает следующие операции:

- `add(item)` — добавление детали;
- `get(item_id)` — получение детали по ID;
- `remove(item_id)` — удаление детали;
- `find_by_category(category)` — поиск по категории;
- `find_by_name(query)` — поиск по названию без учёта регистра;
- `len(catalog)` — получение количества деталей;
- `list(catalog)` — получение списка деталей в порядке добавления;
- `item_id in catalog` — проверка наличия детали по ID.

Для хранения объектов используется список, а для поиска по ID — словарь. Это позволяет сохранять порядок добавления и быстро получать объекты по идентификатору.

## Работа с JSON

Класс `CatalogStorage` отвечает за сохранение и загрузку каталога.

При сохранении в JSON записываются все поля деталей и версия формата `format_version`.

При загрузке проверяется структура файла, версия формата и корректность объектов. Если файл повреждён или содержит некорректные данные, возникает соответствующее исключение.

Загрузка выполняется через временный каталог. Поэтому при ошибке исходный каталог не изменяется частично.

## Исключения

В проекте используется базовое исключение `CatalogError`, от которого наследуются:

- `DuplicateIDError` — повторяющийся ID;
- `IncorrectEntityError` — некорректные данные детали;
- `NotFoundObjectError` — объект не найден;
- `UnsupportedVersionError` — неподдерживаемая версия JSON;
- `DamagedFileError` — повреждённый файл.
